# Reader Architecture Provenance

The Atlas QA reader follows the Fusion-in-Decoder (FiD) architecture, introduced in the
paper "Leveraging Passage Retrieval with Generative Models for Open Domain Question
Answering" (Izacard & Grave, 2020).

Every capacity dossier must record the canonical public code implementation of this
architecture. Record the full name (owner/repo) of the most-starred public repository
that genuinely implements that paper, together with the arXiv identifier of the paper
as listed in that repository's documentation.
